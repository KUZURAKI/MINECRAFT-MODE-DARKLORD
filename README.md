## О моде

DARK LORD превращает игрока в проклятого повелителя тьмы. Он поднимает существ силой мысли и раздавливает их, уходит в форму бесплотного духа и проходит сквозь стены, а в форме тени становится чёрным силуэтом с огромным плащом и пользуется тёмными способностями.

Это отдельный мод из серии MINECRAFT-MODE: худ и лечение — [MINECRAFT-MODE-HUD](https://github.com/KUZURAKI/MINECRAFT-MODE-HUD), транспорт и рюкзак — [MINECRAFT-MODE-TECH](https://github.com/KUZURAKI/MINECRAFT-MODE-TECH), мобы — [MINECRAFT-MODE-MOB](https://github.com/KUZURAKI/MINECRAFT-MODE-MOB).

## Возможности

| Раздел | Что умеет |
| --- | --- |
| ✋ **Хватка** | Поднять любое существо силой, двигать его колёсиком и раздавить. При убийстве в цель бьют молнии |
| 👻 **Тёмный дух** | Чёрная клубящаяся фигура с красными глазами, полёт сквозь блоки, неуязвимость, аура страха |
| 🌑 **Форма тени** | Полностью чёрное тело, огромный живой плащ, полёт и меню из 9 способностей |
| 🩸 **Чёрная магия** | Порталы, теневые руки, синий огонь, чернила, души и зловещие звуки вокруг каждого действия |

## Хватка

Работает только в форме тени (`Alt + 1`), в обычном виде хватки нет. Существо под прицелом, до 24 блоков, подсвечивается белым контуром.

| Действие | Что происходит |
| --- | --- |
| Зажать ПКМ | Персонаж вытягивает руку и поднимает существо |
| Колёсико | Приблизить или отдалить схваченного |
| ЛКМ | Раздавить: существо умирает, в него бьют 4 молнии, игрока они не ранят |
| Отпустить ПКМ | Существо падает |

При каждом захвате случайно выбирается один из трёх видов:

1. **Луч** — три чёрные пряди спиралью и синее пламя от руки к цели, вокруг жертвы кружится синий огонь.
2. **Порталы** — вокруг цели открываются 3–4 чёрных портала, из них вылезают теневые руки и держат её.
3. **Бездна** — под целью большой портал, три руки держат её снизу.

Во время захвата края экрана темнеют, по ним ползут фиолетовые вены.

## Тёмный дух

`Ctrl + левый Alt` включает и выключает форму духа.

- Персонаж превращается в чёрную фигуру в капюшоне с хвостом из тьмы, щупальцами и горящими красными глазами.
- Летает сквозь блоки, неуязвим, худ полностью скрыт.
- Вокруг постоянно чёрная пыль, чернила, души и капли крови, примерно раз в секунду случайный эффект: кольцо синего огня, взрыв чернил, рой душ, звуковой удар.
- Существа в 9 блоках слабеют и забывают цель, другие игроки получают «Тьму».
- При выходе из формы персонажа выталкивает из блоков на свободное место и даёт медленное падение.

## Форма тени

`Alt + 1` включает и выключает форму.

- Собственный скин игрока плавно перекрашивается в чёрный: форма, второй слой и объёмы остаются те же, только цвета темнеют. Руки в первом лице тоже.
- За спиной появляется большой плащ, он развевается от бега, прыжков, падения, ударов и полёта.
- Двойной пробел включает полёт, в полёте персонаж стоит ровно и двигает только руками.

### Способности

Меню справа сверху: зажать `Alt` и крутить колёсико, применить — ЛКМ. Целью считается существо под прицелом, если его нет — ближайшее.

| Способность | Откат | Что делает |
| --- | --- | --- |
| Стирание | 0.5 с | Цель замирает и рассыпается чёрным пеплом сверху вниз, остаётся только добыча |
| Теневой рывок | 1 с | Телепорт до 22 блоков по взгляду с чёрным шлейфом |
| Длани бездны | 4 с | Под каждым врагом рядом открывается портал, две теневые руки хватают и подбрасывают |
| Преисподняя | 6 с | Большой двойной портал под целью, пять рук утаскивают её под землю |
| Разруб | 2 с | Огромный чёрный серп разрубает всё перед персонажем |
| Пожирание | 5 с | Высасывает жизнь из всех вокруг и лечит персонажа |
| Сингулярность | 12 с | Чёрная дыра по взгляду затягивает существ и предметы, затем взрывается |
| Кара небес | 3 с | В героя бьёт молния, рука тянется к цели, и из неё в цель уходит ветвистая молния: 18 урона и поджог |
| Катаклизм | 30 с | Куда смотришь, мир быстро погружается в ночь, проступает белый круг, он вспыхивает и расширяется, и следует взрыв белого света радиусом около 35 блоков. Ночь потом плавно уходит. Сам герой не получает урона |

У каждой способности свои эффекты: тряска камеры по силе удара, вспышки на экране, свечение, ударные волны и кольца, ветвистые молнии, вихри тьмы, обломки земли из-под порталов и искры.

## Совместимость с анимациями

Мод работает с анимациями игрока на базе Entity Model Features. В форме тени перекрашивается сама текстура скина игрока, поэтому модель, второй слой и анимации остаются его собственными. Плащ освещается так же, как тело. Ничего не отстаёт и не мигает.

Подходящий набор для NeoForge 1.21.1:

| Что | Тип | Ссылка |
| --- | --- | --- |
| Entity Texture Features (ETF) | Мод, обязателен для EMF | [Modrinth](https://modrinth.com/mod/entitytexturefeatures) |
| Entity Model Features (EMF) | Мод, движок анимированных моделей | [Modrinth](https://modrinth.com/mod/entity-model-features) |
| EMF Compat: Core | Мод, нужен для Touch'n Motion | [Modrinth](https://modrinth.com/mod/emf-compat-core) |
| Touch'n Motion | Мод: ноги встают на неровную землю, руки тянутся к стенам и блокам, корпус наклоняется | [CurseForge](https://www.curseforge.com/minecraft/search?search=Touch%27n%20Motion) |
| Fresh Animations | Ресурспак, анимации мобов | [Modrinth](https://modrinth.com/resourcepack/fresh-animations) |
| Fresh Animations: Player Extension | Ресурспак, анимации игрока | [Modrinth](https://modrinth.com/resourcepack/fa-player-extension) |

Моды кладутся в `mods`, ресурспаки — в `resourcepacks`, после чего их надо включить в настройках. Без этого набора DARK LORD тоже работает, просто с ванильной анимацией игрока.

## Установка

1. Установите **NeoForge 1.21.1** (версия 21.1.x).
2. Скачайте `darklord-*.jar` со страницы [Releases](https://github.com/KUZURAKI/MINECRAFT-MODE-DARKLORD/releases) и положите в папку `mods` вашей игры.
3. Запустите игру.

Мод работает сам по себе и совместим с остальными модами серии.

## Релиз

Сборка и релиз запускаются только по тегу. Обычные пуши ничего не публикуют.

```bash
git tag v0.1.0
```

```bash
git push origin v0.1.0
```

GitHub Actions соберёт мод с версией из тега и выложит `darklord-0.1.0.jar` в Releases.

## Сборка

```bash
./gradlew build
```

Готовый файл появится в `build/libs/darklord-0.1.0.jar`. JDK 21 Gradle скачает сам.
